Use the controls below to create a backup or restore system data.

Data Restoration Procedure

  1. Identify data loss or corruption.
  2. Navigate to Backup Management.
  3. Select Restore Latest Backup.
  4. Wait for confirmation.
  5. Verify system data accuracy.

Manual Backup Procedure

  1. Navigate to Backup Management.
  2. Select Create Backup Now.
  3. Wait for confirmation.
  4. Continue operations.
