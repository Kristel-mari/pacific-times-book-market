# Pacific Times Book Market

A Flask bookstore web app with a customer storefront and employee inventory tools.

## Features
- Search books by title, author, and category
- Shopping cart
- Live inventory updates
- Employee sign-in page
- Employee dashboard
- Receive invoice / restock inventory

## Run locally
1. Install Flask:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000
